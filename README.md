# convcode_from_generators

## Описание

Проект направлен на реализацию класса для работы со сверточными кодами.

Основная цель — создать универсальный инструмент, позволяющий генерировать объект на основе пользовательских матриц, который может выполнять кодирование и декодирование данных.

Порождающие матрицы задаются в 8-ричной системе счисления.

---

## Возможности

- Задание пользовательских порождающих матриц  
- Генерация сверточного кода  
- Кодирование входной последовательности  
- Декодирование с использованием разных алгоритмов

---

## Декодирование

Реализация следующих алгоритмов декодирования

### Алгоритм Витерби
Реализуется алгоритм декодирования по критерию МП (ML)

### Алгоритм ФАНО

### Feed Back

### Стековый алгоритм

### SOVA
Алгоритм Витерби с мягкими решениями

### BCLR

Алгоритм декодирования, который выдает мягкие решения. Алгоритм реализует декодирование для каждого символа по критерию МАВ (MAP)

Алгоритм может задавать в себе следующие улучшения и оптимизации:

- Log - APP
- MAX - Log - APP
