# convcode_from_generators

## Описание

Проект направлен на реализацию класса для работы со сверточными кодами.

Основная цель — создать универсальный инструмент, позволяющий генерировать объект на основе пользовательских матриц, который может выполнять кодирование и декодирование данных.

Порождающие матрицы задаются в 8-ричной системе счисления.

---

## Возможности

- Задание пользовательских порождающих матриц  
- Генерация сверточного кода  
- Кодирование входной последовательности  
- Декодирование с использованием алгоритма Витерби  
- Декодирование с использованием алготмов BLAST\VBLAST 

---

## Назначение

Проект может использоваться для:

- Изучения теории кодирования  
- Моделирования систем передачи данных  
- Исследования и тестирования алгоритма Витерби
